# best-national-statistics-site-20261126-0539

Nusantara Stats — Indonesia in Numbers is an independent, authoritative statistical portal presenting verified official figures on Indonesia's economy, demographics, trade, and provincial development. Built with zero external network dependencies and pure hand-drawn SVG charts.

## Run it
```bash
node main.ts
```
